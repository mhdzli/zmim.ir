# Simorq

Simorq is a minimal Jekyll theme for blogging. With a simple config file change, you can easily use it to set up your own personal blog.

This project started as a fork of the [`klise`](https://klise.now.sh){:target="\_blank"}{:rel="noopener noreferrer"} theme, which is available [here](https://github.com/piharpi/jekyll-klise){:target="\_blank"}{:rel="noopener noreferrer"}.

For Persian date support, I used the [`jekyll-jalali`](https://github.com/mehdisadeghi/jekyll-jalali){:target="\_blank"}{:rel="noopener noreferrer"} plugin written by [Mehdi Sadeghi](https://github.com/mehdisadeghi/){:target="\_blank"}{:rel="noopener noreferrer"}, who also has a lot of great content on [his blog](https://mehdix.ir/){:target="\_blank"}{:rel="noopener noreferrer"} — definitely worth visiting if you plan to use Jekyll.

## Update

In the latest update, the `jekyll-jalali` plugin and the Persian number conversion scripts were replaced with the [`persiandate`](https://github.com/mhdzli/simorq/blob/master/src/assets/js/persiandate.js) script.

This theme uses the [`Vazirmatn`](https://github.com/rastikerdar/vazirmatn) font, a beautiful work by [Rastikerdar](https://github.com/rastikerdar), for whom I am very grateful, and [`Comic Mono`](https://dtinth.github.io/comic-mono-font/) for inline code.

## Features

- [x] Dark and light theme
- [x] Persian date support
- [x] Appearance customization via scss
- [x] Responsive for desktop and mobile
- [x] Proper image structure ([`jekyll-postfiles`](https://github.com/nhoizey/jekyll-postfiles){:target="\_blank"}{:rel="noopener noreferrer"})
- [x] Sitemap ([`jekyll-sitemap`](https://github.com/jekyll/jekyll-sitemap){:target="\_blank"}{:rel="noopener noreferrer"})
- [x] RSS feed ([`jekyll-feed`](https://github.com/jekyll/jekyll-feed){:target="\_blank"}{:rel="noopener noreferrer"})
- [x] Code highlighting ([`Comic Mono`](https://dtinth.github.io/comic-mono-font/))
- [x] Post pagination
- [x] Comment support. To add a comments section using Mastodon, read [this post](https://www.zmim.ir/mastodon-comments/).
- [x] Google Analytics if you want to use it. (Please don't 😠)
- [x] W3C support **👽**
- [x] Font Awesome support **👽**
- [x] Lightweight and fast **🚄**

## Installation

To run a local server on your system:

<div class="code-block">
{% highlight bash %}
$ git clone https://github.com/mhdzli/simorq.git
$ cd simorq
$ bundle install
$ bundle exec jekyll serve
{% endhighlight %}
</div>

You can view the result in your browser at `localhost:4000`.

## Limitations

- Since [`jekyll-postfiles`](https://github.com/nhoizey/jekyll-postfiles#compatibility){:target="\_blank"}{:rel="noopener noreferrer"} and [`jekyll-jalali`](https://github.com/mehdisadeghi/jekyll-jalali){:target="\_blank"}{:rel="noopener noreferrer"} are not supported on `github pages`, you cannot use this theme directly on GitHub Pages. However, you can use [`netlify.com`](https://netlify.com){:target="\_blank"}{:rel="noopener noreferrer"}, [`vercel.com`](https://vercel.com){:target="\_blank"}{:rel="noopener noreferrer"}, or [`surge.sh`](https://surge.sh){:target="\_blank"}{:rel="noopener noreferrer"}.

### Update

With the addition of `jekyll` to `GitHub Actions`, you can now also deploy Simorq on GitHub. Simply set the `Build and deployment` option to `GitHub Actions` in the `Pages` section of your repository settings, then build and deploy using `Jekyll`. You can see a live example [here](https://theme.zmim.ir/).
