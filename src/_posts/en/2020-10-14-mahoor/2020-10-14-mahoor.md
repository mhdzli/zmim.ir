# Mahour

Mahour is an extension for the Thunderbird email client that adds a Solar Hijri (Jalali/Persian) date column. The legacy extension [Iranian Date For Thunderbird](https://addons.thunderbird.net/en-US/thunderbird/addon/iranian-date-for-thunderbird/?src=ss){:target="_blank"}{:rel="noopener noreferrer"} stopped working after version 68.

<div style="text-align: center;">
    <img src="/mahoor/mahour.png" style="max-width: 80%; margin: 10px;" alt="Mahour extension">
</div>


The Mahour extension code is available on <a href="https://github.com/mhdzli/mahour" target="_blank" rel="noopener noreferrer"><i class="fab fa-github"></i></a>.

## Installation

- Install from the [Mozilla Add-ons Repository](https://addons.thunderbird.net/en-us/thunderbird/addon/mahour-iranian-date/){:target="_blank"}{:rel="noopener noreferrer"}
- Download and install manually:
	- Download the latest `XPI` file from <a href="https://github.com/mhdzli/mahour/releases" target="_blank" rel="noopener noreferrer"><i class="fab fa-github"></i></a>.
	- In the `Add-ons Manager` page, click on `Tools for all add-ons` (<i class="fa fa-cog"></i> <i class="fa fa-chevron-down"></i>). Use the `Install Add-on From File...` option to select and install the downloaded file.

## Building the `XPI` File from Source

`XPI` files are `ZIP` archives that Mozilla uses with the `xpi` extension.

- Download the source code from <a href="https://github.com/mhdzli/mahour/archive/master.zip" target="_blank" rel="noopener noreferrer"><i class="fab fa-github"></i></a> and extract it, or use `git clone https://github.com/mhdzli/mahour`.
- In a terminal, navigate to the `src` folder inside the extension code and build the extension file using: `zip -r mahour.xpi *`
